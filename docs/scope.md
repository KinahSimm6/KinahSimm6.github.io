# Project Scope Statement

## Project Purpose

The main purpose of this project is to create a simple personal website using HTML and CSS while demonstrating basic web development and project management skills.

## Project Description

I will create a two-page personal website that introduces me, my professional and educational interests, goals, hobbies, and interests. The website will include a homepage (`index.html`) and an About page (`about.html`) connected through navigation. A single external stylesheet (`style.css`) will provide consistent styling across both pages. The website will also include a link to my GitHub profile.

## Desired Results

The completed website should:

- Clearly introduce me to visitors.
- Be organized and easy to navigate.
- Demonstrate my understanding of basic HTML and CSS.
- Include a homepage and an About page.
- Use consistent styling across both pages.
- Include working navigation between pages.
- Contain a working link to my GitHub profile.
- Be published through GitHub Pages.

## Exclusions

This project will not include:

- JavaScript
- Databases
- Forms
- User accounts or authentication
- Advanced interactive website features

The focus will be on creating a simple, functional two-page website while demonstrating proper HTML structure, basic CSS styling, documentation, and project planning.
